# Experimental Fluid Dynamics – Laboratory 2

Data analysis for the second laboratory of the **Experimental Fluid Dynamics** course
(Politecnico di Milano, A.Y. 2026/27): aerodynamic characterization of a **NACA 23012** airfoil
in a wind tunnel, with direct comparison against **XFOIL** predictions.

The experimental activity consists of two tests:

1. **Pressure distribution on the airfoil.** From 16 pressure taps (8 on the upper surface, 8 on the lower surface)
   the pressure coefficients $C_p$ are computed and, by integration, the lift coefficient $C_L$
   as a function of the angle of attack.
2. **Wake analysis.** A hot-wire anemometer measures the wake velocity profile at $\alpha = 10°$:
   from it we obtain the drag coefficient $C_D$ (momentum deficit method), the turbulence intensity,
   and the velocity spectra, which are compared with Kolmogorov's law (K41).

All measured quantities come with a 95 % expanded uncertainty (see [Uncertainties](#uncertainties)).

## Usage

Scripts must be run from the repository root, since they use relative paths.

```bash
git clone https://github.com/RiccardoRivetti/FluidodinamicaSperimentale-LAB2.git
cd FluidodinamicaSperimentale-LAB2
```

### 1. Test 1 – Pressures and lift

```bash
# Mean Cp and uncertainties for each angle  ->  Output/Cp/Cp_aoa_*.csv
python compute_pressure.py Data/airfoil_pressures.csv

# Lift coefficient  ->  Output/CL.csv
python compute_lift.py Data/airfoil_pressures.csv

# Plots  ->  Figures/
python plot_lift.py Output/CL.csv
python plot_pressure.py Output/Cp --alpha 6
```

`--alpha` selects the angle to plot (it must be among the measured ones; file names use `m` for negative
values and `_` in place of the decimal point, e.g. `Cp_aoa_m2.csv`, `Cp_aoa_11_5.csv`).

### 2. Test 2 – Wake, drag and spectra

```bash
# CD, turbulence intensity and velocity profile  ->  Output/wake.csv
python compute_drag.py Data/hot_wire

# Spectra: one for each height z of interest  ->  Output/spectrum/*.npz
for z in 152.5 170.0 200.0; do
    python compute_spectrum.py Data/hot_wire/10deg_Z$z.dat
done

# Plots  ->  Figures/
python plot_wake.py Output/wake.csv
python plot_spectrum.py -z 152.5 170 200
```

All `plot_*` scripts accept the `--plot` option to display the plots on screen in addition to saving them.
`plot_spectrum.py` requires the `.npz` files for the three chosen heights to have already been generated by `compute_spectrum.py`.

## Methods

### Pressure coefficient and lift
The dynamic pressure is obtained from the reference signal through the wind tunnel calibration constant
(`K_WT`), and the pressure coefficient is $C_p = p / q$ for each tap. The lift coefficient is obtained by
numerically integrating (trapezoidal rule) $C_p$ along the upper and lower surfaces:

$$C_L = -\int C_{p,\mathrm{upper}}\,\mathrm{d}(x/c) + \int C_{p,\mathrm{lower}}\,\mathrm{d}(x/c)$$

### Drag coefficient
$C_D$ is computed by integrating the momentum deficit in the wake:

$$C_D = \frac{2}{c}\int \frac{V}{V_\infty}\left(1-\frac{V}{V_\infty}\right)\mathrm{d}z$$

The freestream velocity $V_\infty$ is estimated automatically from the points outside the wake (the median of
the edge points is used to locate the wake, then the mean of the points outside it is taken). The value is then
corrected for the effect of the longitudinal pressure gradient in the test section (*horizontal buoyancy*).
The script prints the computed $C_D$, the corrected one, and the one predicted by XFOIL at $\alpha = 10°$.

### Turbulence and spectra
- **Turbulence intensity:** $I_u = \sigma_u / V$, where $\sigma_u$ is the standard deviation of the hot-wire signal.
- **Amplitude spectrum:** FFT of the mean-removed signal.
- **Energy spectrum:** Welch estimator (Hann window, 50 % overlap) converted to wavenumber
  through Taylor's hypothesis, $k = 2\pi f / \bar{V}$.
- **K41 comparison:** the dissipation rate $\varepsilon$ is estimated in the inertial range (100 ≤ k ≤ 1000) and used to
  draw the theoretical spectrum $E(k) = C\,\varepsilon^{2/3} k^{-5/3}$.

### Uncertainties
For $C_p$ and $C_L$ the uncertainty combines:
- **type A:** standard error of the mean over repeated acquisitions;
- **type B:** accuracy of the pressure transducer (rectangular distribution), propagated to the coefficient.

The reported expanded uncertainty is $U = 2\,u_c$ (95 % confidence interval, $k = 2$). In the output files the
columns are `Cp_mean` (or `Mean`), `Cp_unc` (or `Unc`), `u_A`, `u_B`.

## Experimental setup

The parameters used in the calculations are collected in `experimental_setup.py`:

- **Airfoil:** NACA 23012, chord 0.100 m, span 0.293 m, thickness 12 %
- **Test section:** 0.30 m × 0.45 m
- **Pressure transducers:** Delta OHM HD4V8T
- **Wake velocity measurements:** hot-wire anemometer, sampling frequency 25 kHz
